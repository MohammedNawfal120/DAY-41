# Day 41 - Bootstrap Forms Task

This is a responsive Services webpage built with React, Vite and Bootstrap 5.

## Requirements completed

1. Bootstrap buttons (`btn-primary`, `btn-outline-success`, `btn-warning`, `btn-outline-dark`) and a dismissible success alert.
2. Controlled Contact Us form containing name, email, and message; uses `form-label` and `form-control`. Built-in required/email validation. Submit displays a success message; this is a demo (no backend).
3. Navbar, three service cards, and form combined on a responsive Services Page.

## Run

```bash
npm install
npm run dev
```

Use the localhost URL printed by Vite. For a production build run `npm run build`.

## Test

- Click each button to see the style name displayed.
- Dismiss the green alert using its X button.
- Fill and submit the form to see a success message.
- Resize the window and use the navbar menu on mobile.
